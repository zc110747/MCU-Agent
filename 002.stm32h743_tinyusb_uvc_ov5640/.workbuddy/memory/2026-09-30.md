## 全局变量 static 化 + 结构体化（mcu-code-style §2/§3/§4）

用户要求：所有文件级可变全局 → `static` + 分组进结构体；跨文件使用的单独函数接口暴露，暴露多的用结构体指针。例外：`const`（flash，不结构化）、HAL `*_HandleTypeDef`（保留 extern）。

### 落地（app/main.c, app/uvc_app.c, bsp/bsp_camera.c + 两 header）
- `bsp_camera.c`：~56 个 `cam_*` 文件级可变全局 → 8 个子结构体合进容器 `static cam_diag_t s_cam_diag`（stats/ctl/pin/bus/pull/regdump/snap/poke）；`cam_reg_addr` 改 `static const`（flash 例外，不进结构体）
- `uvc_app.c`：`uvc_pipeline_t` 改名 `uvc_app_t`，17 个 `uvc_*`/`usb_*` 遥测成员并入 → `static uvc_app_t s_uvc`
- `main.c`：`g_cam_status/g_cam_id/g_loop_count` → `static app_state_t s_app`
- 跨文件引用检查：**无**候选全局被其它 .c 使用（仅 header 里为 SWD 读符号留了 extern 死声明）→ 全部删除死 extern，无需函数/结构体指针暴露
- `bsp_camera.h` 保留 HAL handle extern（hdcmi/hdma_dcmi/hi2c_cam）

### 修复两个构建阻断 bug（首次双构验证时暴露）
1. **注释终止符 bug**：注释里的字面量 `uvc_*/usb_*`（uvc_app.h:28、uvc_app.c:62）中 `*/` 提前关闭注释块，残留 `usb_ ` 等变成垃圾代码 → 级联报 `s_uvc undeclared` + bsp_camera.h `cam_status_t` 错误。改 `uvc_ and usb_`。**教训：注释里写 `x_*/y_*` 通配会把注释截断，写 glob 用 `x_ and y_` 或 `x_/y_`。**
2. **结构体漏字段**：rename 脚本把 `usb_mounted/usb_mount_count/usb_suspend_count/usb_commit_count` 的引用改成了 `s_uvc.xxx`，但结构体字段没加 → 编译报 no member。补全 4 个 `volatile uint32_t` 字段。
