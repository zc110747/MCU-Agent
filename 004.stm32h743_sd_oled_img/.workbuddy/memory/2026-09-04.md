## bsp_log 改造：printf → 非阻塞 PRINT_LOG（环形缓冲 + TXE 中断）
- 参考工程 003.stm32h743_lvgl_oled 的 Bsp/log.c|log.h（缓存 + 发送完成中断）实现，移植到本工程 bsp/bsp_log.c|h。
- 实现要点：printf_log 格式化进栈缓冲 → 推入 1024B TX 环形缓冲；uart_write 关 TXE 中断改索引后启动首个字节；USART1_IRQHandler 调 log_uart_tx_irq() 逐字节 drain；TXE 空后停中断。调用方永不阻塞 UART。
- 已删除 LOG_I/LOG_W/LOG_E 宏及所有调用点，统一改用 PRINT_LOG。原 `[I]/[W]/[E]` 前缀与 `\r\n` 直接写进格式串（如 `PRINT_LOG("[E] ...\r\n", ...)`）以保留日志语义。
- PRINT_LOG_ENABLE 宏开关：=-D 或 #define 为 0 时 PRINT_LOG 展开为 `((void)0)`，printf_log 等被死代码消除（已验证 FLASH 体积不变、0 警告）。
- 新增 Core/Src/stm32h7xx_it.c 的 USART1_IRQHandler（含 #include "bsp_log.h"）。
- 验证：Debug + Release 双构建均 0 警告；额外用 -DPRINT_LOG_ENABLE=0 构建验证关闭路径 0 警告。Release：FLASH 58304B/2MB(2.78%)，RAM_D1 163424B/512KB(31.17%)。
- 真机验证：OpenOCD 烧录 build/release/stm32_sd_oled.bin（Verified OK），复位后串口(COM19 ST-Link VCP, 115200)经 pyserial 抓取 6s，成功收到完整开机横幅/SD信息/文件扫描/幻灯片帧打印，确认非阻塞 PRINT_LOG(TXE中断) 端到端工作正常、格式与换行正确。注意：OpenOCD(libusb)触碰 ST-Link 后首次开 VCP 会"拒绝访问"，需重试（脚本已加 7 次重试+延时）才成功打开。
