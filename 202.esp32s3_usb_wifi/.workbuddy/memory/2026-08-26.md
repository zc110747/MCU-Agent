# 2026-08-26 ESP32-S3 USB RNDIS Wi-Fi 网卡项目

## 环境
- 工具链安装路径改为 **D:/software/esp32-tools**
  - IDF_PATH = D:/software/esp32-tools/esp-idf
  - IDF_TOOLS_PATH = D:/software/esp32-tools/tools
- 后台克隆 ESP-IDF **v5.5.5**（shallow + recursive）并安装 esp32s3 工具链：task `4c7BKP`（进行中）
- 安装完成后需配系统环境变量，使 `idf.py` 在任意终端直接可用
- 沙箱无物理 ESP32-S3/CH343 硬件 → 无法真机烧录/USB 枚举验证，只能严格编译 + 给出真机测试步骤

## 已写代码（稳定公开 API，不依赖 TinyUSB 内部）
- `main/config/config_manager.*`：NVS 存 Wi-Fi 凭据，密码不打印；factory reset
- `main/wifi/wifi_manager.*`：STA 扫描/连接/自动重连(5次)/状态查询；连接/断开同步 `SYS_EVT_WIFI_CONNECTED`
- `main/web/index.html`：深色极简配置页（状态/扫描/连接/恢复出厂），EMBED_FILES 嵌入
- `main/web/web_ui.*`：status/scan/result JSON 构造（手动拼，含 SSID JSON 转义）
- `main/web/web_server.*`：esp_http_server，/、/api/status、/api/scan、/api/connect、/api/reset
- `main/system/system_manager.*`：全局状态事件组（USB/RNDIS/Wi-Fi/Net 位）
- `main/main.c`：分阶段启动骨架，USB RNDIS init 暂留注释待 Phase 2 接入
- `CMakeLists.txt` + `main/CMakeLists.txt`：工程骨架（REQUIRES 暂不含 tinyusb/lwip）
