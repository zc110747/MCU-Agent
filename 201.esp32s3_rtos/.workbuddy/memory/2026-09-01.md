## 关键 bug 修复：cmd 括号地狱致 "此时不应有 ."
- 现象：脚本一跑就报 `此时不应有 .。`，编译行/ cd 行单独测都正常，唯独完整脚本挂。
- 根因：`if %errorlevel% neq 0 ( ... echo [ERR] Build failed (exit %errorlevel%). ... )` 块内 echo 文本里的 `)`（紧跟 `%errorlevel%` 后）**提前闭合 if 块**，使后续 `. Full log...` 变成非法语法。cmd 运行前先整体解析块，故即使编译成功(errorlevel=0)也报语法错。
- 修复：把块内 echo 文本里的 `)` 转义为 `^)`（第 81、122 行）。验证：build 路径 `[BUILD] PASS`；失败路径(传 `COM99`)正确打印 esptool 真实错误并给出提示。
- 附：`%~dp0` 带尾斜杠，`cd /d "%~dp0."` 用 `.` 收尾避免 `\"` 转义引号（本例实际未触发，但保留为正确写法）。
