# 2026-08-28 — 第二版：TIM7 时基 + microSD(SDIO) + 启动加载器

## 需求（用户原话拆解）
1. HAL 时基 TIM11 → **TIM7**；已有 FreeRTOS（堆在 SDRAM）保留
2. LVGL 作为**独立任务**显示处理，缓存在 SDRAM（核对后确认第一版已满足）
3. 增加 **SD 卡读取**，读取失败再等 USB 读取，成功后加载字库
4. LVGL：默认界面只有**英文、内部 ascii**，居中 `wait for system start...`；
   字库加载成功 → 主界面（设备状态信息）；**超时 10s** → 居中 `sdcard and usb loader failed!`
5. OpenOCD + ST-Link 真机验证

## 实现
- `app/stm32f4xx_hal_timebase_tim.c` 重写为 htim7；`stm32f4xx_it.c` 换 `TIM7_IRQHandler`
  （TIM7_IRQn=55，**独立向量**，启动文件 vector 470 已有；TIM11 需与 TIM1 TRG/COM 共用）
- 新增 `bsp/bsp_sdio.c/.h`：PC8-12 + PD2 AF12，4-bit，**轮询不接 DMA**，ClockDiv=2 → 卡时钟 12 MHz
  （SDIOCLK 48 MHz = PLLQ=7，与 USB 同源）
- 新增 `app/fs_diskio.c/.h`：统一 diskio 胶水（pdrv0=USB MSC / pdrv1=SDIO）+ `fs_lock` 互斥量；
  SD 路径对**未对齐 4 字节**的缓冲区经 `s_sd_scratch[512]` 中转（HAL 内以 uint32_t* 读 FIFO）
- 新增 `app/sd_card.c/.h`：SDIO init + `f_mount("1:")`，失败不锁存（可重试），`sd_card_set_quiet()`
- `bsp/bsp_lcd_text.c`：`lcd_driver_font_init(const char *vol)` 参数化卷前缀（"1:"/"0:"），
  新增 `lcd_driver_font_source()`；切换卷前 `f_close()` 旧文件 + `lv_font_gbk_reset_cache()`
- `app/app_ui.c`：新增 `app_ui_show_centered()`（清屏 + 单条居中标签，纯 ASCII 走编译期字表）
  + `ui_teardown()`（**必须先 `lv_timer_del()` 再 `lv_obj_clean()`**，否则定时器持悬空 lv_obj_t*）
- `app/ui_task.c`：启动加载状态机（见 README §3.2.1）
- `FF_VOLUMES` 1 → 2；`HAL_SD_MODULE_ENABLED` 开；CMake 加 `hal_sd.c` + `ll_sdmmc.c`
- 新增 `tools/verify_serial/verify_boot_flow.py`（17 项 pass/fail）、`capture_reset.py`

## 本轮踩的三个坑（都已修，见 README §6.1）
1. **UART TX 环形缓冲溢出静默丢日志**：`UART_TX_BUF_SIZE` 仅 512 B 且 `uart_write()` 满即丢弃，
   而 `file_task` 全量 dump 3 MB 字库/JPG 长期占满缓冲 → 新增日志时有时无、已有日志缺字节。
   修复：缓冲扩到 **2048**；dump 加两道闸（>2048 B 文件只列不 dump；整轮预算 16 KB）。
2. **SD 空卡槽刷屏**：每 500 ms 打一次 `SDIO init FAILED`。修复：`sd_card_set_quiet()`，
   首次失败后静音，10s 后探测降频到 3s（热插拔恢复保留）。
3. **超时页重复触发**：deadline 分支写成 `s_state != LOAD_OK`，但 `LOAD_FAILED` 同样满足 →
   每 5ms 打印一次。修复：改为 `s_state == LOAD_BOOT`。

## 调试技巧
- `capture_reset.py` 只复位不烧录，抓控制类日志；改了代码后**必须先烧录再抓**，否则跑的是旧固件
  （这点坑了一次：修完重复打印后只跑 capture_reset，看到的还是旧行为）。
- 想复现「无介质」场景而 U 盘又拔不掉时，用编译开关 `-DCMAKE_C_FLAGS="-DXXX=0"` 单独建一个
  临时 build 目录，测完删掉。
- SDIO 无卡时 `HAL_SD_Init()` **不会**跑满 `SDMMC_MAX_VOLT_TRIAL`(65535)：`SD_PowerON()` 在
  第一个 CMD55 无响应即 return，单次失败 <1 ms，可以放心轮询重试。
