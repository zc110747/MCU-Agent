### 从 README 新沉淀的经验（已写入对应 skill）
- `stm32-peripheral-drivers` 新增「十三、UART 物理层与桥接踩坑」（012 项目）：
  环形缓冲必须 `cap-1` 防满/空二义性；7bit+校验时 STM32 字长含校验位、RDR bit7 是校验位
  （现象：7N1 通而 7E1/7O1 全败，8E1/8O1 不受影响）；RTS 配 AF 却未开 HwFlowCtl → 引脚悬空；
  Windows usbser.sys 只转发 DTR 不转发 RTS。
- `stm32-verification-acceptance` 新增 8.6.2：主机侧 `ser.read(in_waiting or 4096)`
  制造 **~30 ms 假延迟**（Windows 读语义要凑满请求字节数），正确写法 `or 1`。
  判定手法：软件回环（绕开外设）与真实回环双路径对照，共同开销必在主机侧。
