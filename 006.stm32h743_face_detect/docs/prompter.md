# 实现基于模型的人脸检测和输出显示的功能

构建STM32平台的vscode项目，实现人脸检测画框并输出到OLED显示中。

项目生成后直接构建，仿真，异常时使用st-link进行单步调试解决。

## 需求和推荐方案

1. 检测模型建议使用CMSIS-NN + STM32Cube.AI
2. 图像采集使用双/三缓冲，再输出到OLED中，避免撕裂
3. 经过AI检测后的图像绘制到屏幕中，帧率可以较低
4. 检测到人脸立即显示，检测不到时多次判断，且延时0.5s移除(使用宏定义)，避免误检测
5. 剩余空间可补充其它信息，如画面上人脸的数目，当前帧率等

## 硬件资源(详细原理图见附件，直接解析补充)

1. 芯片STM32H743ZIT6，外部无源晶振25MHZ
2. OLED硬件已经连接，可直接调试，可提供部分已验证驱动代码
3. 摄像头为ov5640，可裁剪只输出96x96，再进行AI运算
4. OLED屏幕尺寸240x240，图像可进行先裁剪后缩放来满足尺寸显示
5. 支持调试串口，连接PA9/PA10

## 编译环境

1. 使用cmake+ninja管理项目
2. 编译工具arm-none-gnueabi-gcc
3. 仿真环境openocd + stlink
4. vscode已经集成Cortex-Debug，可以实现单步仿真，允许仿真调用
5. python已经安装，允许直接调用
6. 上述程序已经添加到系统环境中，生成调试文件时不要使用绝对路径

## 工程模块化

对于部分目录给出结构，项目额外下载要尽可能精简，下载必须即可

1. app: 存放应用逻辑
2. bsp：存放用户开发的驱动程序
3. Drivers: HAL相关放在Drivers目录下
4. third_party: 存放第三方库(如FatFs、lvgl)

其它目录无限制。

## 建议流程

1. 先调试完成ov5640采集、oled显示方案
2. 再集成AI框架和模型
3. 将采集、显示和AI关联起来，实现检测到人脸画框功能
4. 完成后总结项目执行步骤、解决问题，总结在项目下的README.md文件中

## 验收标准

1. 调试仿真，能够正确采集到图像，并按照需求显示到oled中
2. 当图形中有人脸存在时，能够正常识别，并绘制框图，更新其它信息
