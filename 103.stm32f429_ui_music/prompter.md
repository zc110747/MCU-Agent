# 基于stm32相关的skills，实现带UI显示的音乐播放器

1. 首页面等待USB-Host U盘或SD卡加载(满足一个即可)，显示和上个项目一致，成功后进入第二个界面，中文字库同之前项目目录一致
2. 第二个界面为音乐播放器界面，支持音乐名、音乐数目、当前音乐位、进度条(带时间)、下面按键包含上一首，暂停/运行(同一个按键)、下一首，点击后在目录内选择下一首，并保持当前状态(运行/停止)，进度条支持拖动，另外右边有音量加减键和上下进度条(表示当前音量)，带数字
3. 音乐为wav和mp3格式，在U盘/SD卡的music目录下，进入第二个页面会从目录下读取文件，点击播放开始运行，下一首则切换播放音频
4. 支持FreeRTOS系统，参考上一项目进行移植，HAL库时基使用TIM，优先级使用0，0，避免被RTOS影响
5. FreeRTOS、lvgl和音频使用sdram进行缓存

音频播放使用硬件WM8978，硬件接口如下：

SAI1_FSA - PE4
SAI1_SCKA - PE5
SAI1_SDB - PE3
SAI1_SDA - PE6
SAI1_MACKA - PE2

IIC_SCL - PH4
I2C_SDA - PH5

PWM_AUDIO - PA3
