# 2026-08-11 工作日志

## 新增两个 NES 页功能（已实机验证）

1. **中文/UTF-8 ROM 名正确显示（原 bug #1）**
   - 根因双处：
     - FatFs `third_party/FatFs/ffconf.h` 的 `FF_CODE_PAGE` 原为 `437`，会把中文 LFN 转 CP437 丢字符 → 改成 `936`（GBK），`fno.fname` 现返回 GBK（保留中文、保 `f_open` 命中）。
     - `app/page_nes.c` 的 `build_browser` 原先把 GBK 字节直接喂 `lv_label_set_text`，但 `lv_font_gbk_16` 字体驱动是 **UTF-8→Unicode→GBK 字形** 映射，喂 GBK 字节即乱码。改为先 `gbk_to_utf8()` 转 UTF-8 再显示。
   - 串口 `rom list` 经 `gbk_to_utf8` 现正确输出：超级玛丽/导弹坦克/快打旋风中文无敌版/魂斗罗。
   - 注：`_CODE_PAGE` 切勿改回 437，否则中文名再次全乱。

2. **SELECT 键退出程序（原 bug #2）**
   - 运行中：`KEY_SELECT`（同 BACK / MENU）按一下 `stop_game()` → 回 ROM 浏览器（上一界面）。
   - 浏览器中：`KEY_SELECT` → `app_menu_back()` → 回主菜单。
   - `feed_pad()` 已移除 SELECT→NES_PAD_SELECT（设计取舍：用 SELECT 换“退出”，游戏中 SELECT 按钮不再可用）。
   - 入口提示改为「↑↓ 选择  A 运行  SELECT 退」；`start_game()` 串口打印退出方式。

- **UI 优化 2 — SD 浏览器文件夹标识 + SELECT 返回上级**：
  - `app/sd_browser.c` 目录名用 `COL_ACCENT`(橙黄 0xFFA000) 区分文件(白 `COL_TEXT`)，另保留 `/` 前缀与文件夹标记。
  - 状态栏按是否根目录区分：`1:` 根 → "SELECT 退出"；子目录 → "SELECT 上级"。
  - `sd_browser_key` 新增 `KEY_SELECT` 处理：子目录内 → `browser_up()` 返回上一级（不再直接退应用）；根目录 → 返回 0 交 page 退出应用。NES/图像两页的 SELECT 逻辑无需改，自动获得正确行为。
  - 痛点：原先进子目录后按 SELECT 会冒泡到 page 直接退出整个应用。

- **验证**：Release 构建 0 错误 0 警告（`-j4`）；烧录 Verified OK；串口自测 `scripts/serial_test.py --port COM19` **38/38 PASS**（NES 31fps、mapper 0、中文名正确）。文件夹配色 + 子目录 SELECT 返回属屏幕视觉行为，需真机肉眼确认。
