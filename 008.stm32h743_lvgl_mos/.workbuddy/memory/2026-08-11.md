# 2026-08-11 工作日志

## 新增两个 NES 页功能（已实机验证）

1. **中文/UTF-8 ROM 名正确显示（原 bug #1）**
   - 根因双处：
     - FatFs `third_party/FatFs/ffconf.h` 的 `FF_CODE_PAGE` 原为 `437`，会把中文 LFN 转 CP437 丢字符 → 改成 `936`（GBK），`fno.fname` 现返回 GBK（保留中文、保 `f_open` 命中）。
     - `app/page_nes.c` 的 `build_browser` 原先把 GBK 字节直接喂 `lv_label_set_text`，但 `lv_font_gbk_16` 字体驱动是 **UTF-8→Unicode→GBK 字形** 映射，喂 GBK 字节即乱码。改为先 `gbk_to_utf8()` 转 UTF-8 再显示。
   - 串口 `rom list` 经 `gbk_to_utf8` 现正确输出：超级玛丽/导弹坦克/快打旋风中文无敌版/魂斗罗。
   - 注：`_CODE_PAGE` 切勿改回 437，否则中文名再次全乱。

2. **SELECT 键退出程序（原 bug #2）**
   - 运行中：`KEY_SELECT`（同 BACK / MENU）按一下 `stop_game()` → 回 ROM 浏览器（上一界面）。
   - 浏览器中：`KEY_SELECT` → `app_menu_back()` → 回主菜单。
   - `feed_pad()` 已移除 SELECT→NES_PAD_SELECT（设计取舍：用 SELECT 换“退出”，游戏中 SELECT 按钮不再可用）。
   - 入口提示改为「↑↓ 选择  A 运行  SELECT 退」；`start_game()` 串口打印退出方式。

## 浏览器增强：目录可进入 + 行内文字垂直居中

1. **目录显示与进入（用户反馈“看不到目录、无法进下一层”）**
   - `app/sd_browser.c` 的 `scan()` 原先 `continue` 跳过 `AM_DIR`；现改为**目录也列出**（目录名前缀 `/`），且非根目录时列表首项插入 `.. 上级目录` 伪条目。
   - 按键：A/OK/START 命中目录 → 进入子目录（`browser_enter` 拼 `path/sub`）或 `..` → 返回上层（`browser_up` 截掉最后一个 `/`）；命中文件才触发 `on_select`。
   - 目录排序：先 `..`，再目录，后文件（两遍 readdir，跳过 `.`/`..` 真实条目）。
   - `sd_browser_path()` 暴露当前目录，供页面拼全路径：NES `load_rom_named` 与图片 `show_image` 由 `s_dir/IMG_DIR` 常量改为 `sd_browser_path(s_browser)`。
   - `b->path` 缓冲 16→64；`browser_enter` 临时缓冲 128 防 `snprintf` 截断告警（已 0 warning）。

2. **行内文字垂直居中（用户反馈“文字顶上面显示”）**
   - 原手算 `yc` 仅比 y=4 多 1px，观感无变化。改为 `lv_obj_align(lbl, LV_ALIGN_LEFT_MID, x, 0)`，标签在行内真正纵向居中，不依赖字体 `line_height` 度量。
   - 仅修浏览器行（`sd_browser.c`）；主菜单页是两行布局（标题+副说明），用户未提，未动。

## 放弃 FreeRTOS，回退裸机 + UI 优化（本会话后半段）

- **方向调整**：用户要求放弃 FreeRTOS 迁移（曾因 SysTick 被 FreeRTOS 端口独占导致 HAL 时基冻结、SDMMC 初始化卡死；后又发现 FreeRTOS 多线程下 SD 须改 DMA 模式）。代码已回退到裸机稳定版，构建配置同步清理（`startup_stm32h743xx.s` 向量表恢复 `SVC_Handler/PendSV_Handler/SysTick_Handler`；删 `FreeRTOSConfig.h`/`hal_timebase_tim.c`；根 `CMakeLists.txt` 无 FreeRTOS 引用）。`third_party/FreeRTOS/` 目录残留但未引用，构建无影响。

- **UI 优化 1 — 灰色小字调亮**：`app/app_page.h` 的 `COL_DIM` 由 `0x606060` → `0x9CA8B4`（冷亮灰），黑底上小字说明/状态栏清晰得多。影响所有用 COL_DIM 的小字。

- **UI 优化 2 — SD 浏览器文件夹标识 + SELECT 返回上级**：
  - `app/sd_browser.c` 目录名用 `COL_ACCENT`(橙黄 0xFFA000) 区分文件(白 `COL_TEXT`)，另保留 `/` 前缀与文件夹标记。
  - 状态栏按是否根目录区分：`1:` 根 → "SELECT 退出"；子目录 → "SELECT 上级"。
  - `sd_browser_key` 新增 `KEY_SELECT` 处理：子目录内 → `browser_up()` 返回上一级（不再直接退应用）；根目录 → 返回 0 交 page 退出应用。NES/图像两页的 SELECT 逻辑无需改，自动获得正确行为。
  - 痛点：原先进子目录后按 SELECT 会冒泡到 page 直接退出整个应用。

- **验证**：Release 构建 0 错误 0 警告（`-j4`）；烧录 Verified OK；串口自测 `scripts/serial_test.py --port COM19` **38/38 PASS**（NES 31fps、mapper 0、中文名正确）。文件夹配色 + 子目录 SELECT 返回属屏幕视觉行为，需真机肉眼确认。
