# 2026-08-12 工作日志

## DCache 启用 + 内存区域重新规划（最终方案）
- 背景：项目已完成、可编译调试、ST-Link 仿真、串口命令控制。用户要求开启 DCache 并用 MPU 管理 0x24000000 作为 DMA 缓存区。
- 关键事实核查：HAL 的 `HAL_SD_ReadBlocks/WriteBlocks` 走 **polling + SDMMC FIFO**（`SDMMC_ReadFIFO/WriteFIFO`），非 IDMA；SPI6 OLED 为 CPU 阻塞、USB CDC 用 OTG 内部 FIFO、控制台仅 RXNE 中断。→ **全工程无通用 DMA 写 AXI-SRAM**，DCache 无需任何 clean/invalidate 维护，缓存天然一致。
- 最终内存规划（DCache 框架）：
  - RAM_D1 AXI-SRAM 0x24000000：`.data/.bss/heap/stack` + SD 缓冲（栈堆留在最快通用 RAM）。MPU Region0 write-back。
  - RAM_D2 0x30000000：NES ROM。MPU Region1 write-back（6502 取指提速，实测 31→41fps）。
  - DTCM 0x20000000：NES 机器态（TCM 绕过缓存，不配 MPU）。
  - RAM_D3 SRAM4 0x38000000：**未使用**，背景默认 write-through。
- 改动文件：`Core/Src/main.c`（`SCB_EnableDCache()` + `MPU_Config` Region0 改 write-back、新增 Region1）、`app/app_cmd.c`（`status` 新增 `cache: I+D`）、`STM32H743ZITX_FLASH.ld`（修正 SDMMC IDMA 过时注释）。
- 验收：Release 0 错误 0 告警；烧录 Verified OK；`SCB->CCR=0x00070200`（I+D Cache 开）、`CFSR=HFSR=0` 无故障；`sp=0x2407FE88`（栈在 RAM_D1）；`serial_test.py` **38/38 PASS**，NES 41fps。

## 已放弃的尝试：栈堆迁 RAM_D3
- 曾把 `._user_heap_stack` 与 `_estack` 从 RAM_D1 迁到 RAM_D3(SRAM4 0x38000000)，并加 MPU Region2（先 write-back 后 write-through）。

## USB 串口死机：根因与修复
- 用户报告：USB 串口（COM9/TinyUSB CDC）压测工作一段时间死机。要求写循环测试定位并修复。
- 写压测脚本 `scripts/stress_usb.py`：连 USB CDC 高频发命令（合法/非法/超长/burst），连续 N 次无响应判 DEADLOCK。
- 在 DCache 固件上跑压测复现死机，OpenOCD halt 抓现场：`CFSR=0x00008200`(BFSR=0x82 PRECISERR+BFARVALID)、`BFAR=0x00100028`(ITCM 末端后保留空洞，损坏 DMA 描述符导致的野指针)、`HFSR=0x40000000`(FORCED)。
- **根因**：TinyUSB/DWC2 的 DMA 描述符缓冲（`_ctrl_epbuf`+`_dcd_usbbuf`，共 72B）落在 write-back 缓存区，OTG 内部 DMA 与 CPU 缓存不一致 → 描述符损坏 → 非法访问 → BusFault 死机（经典 H7 USB+D-Cache 坑）。`tusb_config.h` 注释还停留在"DCache disabled"印证疏漏。
- **修复**（三处，详见 MEMORY.md "USB 缓存一致性 bug"）：
  1. `STM32H743ZITX_FLASH.ld` 加 `.usb_ram (NOLOAD) >RAM_D3`。
  2. `bsp/tusb_config.h` 定义 `CFG_TUSB_MEM_SECTION` → `.usb_ram`（**注意是 TUSB 非 TUD**）。
  3. `Core/Src/main.c` MPU Region2(0x38000000,64KB) 配 non-cacheable。
  - 注：本项目 `CFG_TUD_EDPT_DEDICATED_HWFIFO=1`，CDC 数据走 OTG 硬件 FIFO，无软件缓冲，故只需 DWC2 描述符 non-cacheable。
- 烧修复版后重新压测验证（结果待补：应 SURVIVED 不死机）。
