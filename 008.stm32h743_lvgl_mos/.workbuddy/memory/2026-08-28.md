# 2026-08-28

## 新增 Keil MDK-ARM 工程（008.stm32h743_lvgl_mos）
- 在工程根目录新建 `MDK-ARM/`，含 `stm32h743.uvprojx`、`stm32h743.uvoptx`、`STM32H743ZITX.sct`。
- 由 `scripts/gen_mdk_uvprojx.py`（按 CMakeLists.txt 生成，可重跑）产出。两个 Target：`Debug`(-O0) / `Release`(-O2)，输出/列表目录 `MDK-ARM/Debug`、`MDK-ARM/Release`（不污染其它目录）。
- 启动文件用 `sys_startup/arm/startup_stm32h743xx.s`（非 gcc 版）；**排除** `Core/Src/syscalls.c`（GCC/newlib 专用）；链接器 **不** 含 `--no-warn-rwx-segments`（Keil 不支持）。
- C 库用 **MicroLIB**（`useUlib=1`，匹配 ST 启动 `__MICROLIB` 分支；非 MicroLIB 路径会引用 armclang 缺的 `__use_two_region_memory`）。
- Defines 镜像 CMake：`STM32H743xx,USE_HAL_DRIVER,HSE_VALUE=25000000,CFG_TUSB_MCU=OPT_MCU_STM32H7,CFG_TUSB_OS=OPT_OS_NONE`；14 个 include 路径全有效。
- scatter 镜像 `STM32H743ZITX_FLASH.ld`：FLASH(2MB)+RAM_D1(512K, .data/.bss)+RAM_D3(64K, usb_ram UNINIT)；**DTCM/RAM_D2 故意不放**（运行时 sram_pool 分配）。
- 修改 `sys_startup/arm/startup_stm32h743xx.s`：Stack_Size/Heap_Size 由 0x400/0x200 提到 **0x2000**(8KB)，匹配 .ld，适配 NES+LVGL+camera 栈需求。
- 文件数：365/Target（Startup1 CMSIS1 Core3 bsp20 app11 HAL121 LVGL192 TinyUSB6 NES5 TJpgDec1 FatFs4）。
- **待办（MicroLIB 代价）**：`bsp_console.c` 的 `_write` 在 MicroLIB 下不生效，需补 `int fputc(int ch,FILE*f){char c=(char)ch;bsp_console_write(&c,1);return ch;}` 让 printf 走 UART1+USB CDC。本机无 Keil，未实编译，仅做结构/约束校验。
