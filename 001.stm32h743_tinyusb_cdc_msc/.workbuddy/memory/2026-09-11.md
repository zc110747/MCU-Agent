# 2026-09-11

## bsp_log: 移植 003 项目的 PRINT_LOG 设计（替代旧 bsp_log_printf 分级 API）
- 用 `003.stm32h743_lvgl_oled/Bsp/bsp_log.{c,h}` 的 PRINT_LOG 机制重写 `001` 的 `bsp/bsp_log.{c,h}`。
- 机制：`PRINT_LOG_ENABLE` 编译期总开关（0=全部编译掉成 ((void)0)）；`printf_log`→`vprintf_log`→`uart_write` 写入 1024B TX 环形缓冲；USART1 **TXE 中断**在 ISR(`log_uart_tx_irq`) 中逐个字节搬 TDR 排空，调用方永不阻塞 UART。
- 关键适配：001 没有 CubeMX `main.h`/`huart1` 全局，因此在 `bsp_log.c` 内声明 `static UART_HandleTypeDef huart1`，由 `bsp_log_init()` 自包含完成 PA9/PA10 AF7 + 115200 8N1 初始化并 NVIC 使能（003 的 `log_uart_init()` 仅开 NVIC，此处保留为兼容导出）。
- 删除旧的 `bsp_log_level_t`/`BSP_LOG_*`/`bsp_log_printf`/`bsp_log_write`/`bsp_log_uart_irq`/`HAL_UART_TxCpltCallback`（003 直接用 TXE ISR，不走 HAL 回调）。
- 调用方改造：`app/stm32h7xx_it.c` 的 `USART1_IRQHandler` 改调 `log_uart_tx_irq()`；`app/main.c` 用 `PRINT_LOG(...)` 替换 `bsp_log_printf(BSP_LOG_INFO, ...)`（init 调用 `bsp_log_init()` 不变）。
- 验证：CMake Debug(0 warn,69.5KB)/Release(0 warn,58.9KB) + MDK UV4(-r 全清, 0 Err/0 Warn, 107KB bin) 三构全绿。
