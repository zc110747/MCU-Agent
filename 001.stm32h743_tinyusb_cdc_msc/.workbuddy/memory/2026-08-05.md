## 已完成验证（端到端）

- **烧录**：OpenOCD + ST-Link(SWD) verify OK。

## 需求更新：改用外部 25MHz 无源晶振 (HSE) 作为时钟源
- 用户明确要求：外部晶振 25MHz 无源晶振（非 HSI）。USB FS PA11/PA12、LED PG7 不变。
- **关键 HAL 坑（重要经验）**：bsp.c `system_clock_config()` 中曾设 `osc.HSIState=RCC_HSI_OFF`。
  复位后系统时钟就是 HSI，HAL_RCC_OscConfig 拒绝关闭"当前系统时钟源" → 返回 HAL_ERROR →
  error_trap 死循环，g_sysclk_hz 永远=0，USB 不枚举。
  修复：不要关 HSI，PLL 仍从 HSE 取，HSI 留着无害。
- **PLL 取值（HSE 25MHz → 400/200）**：M=2(→12.5MHz), N=64(→800MHz VCO), P=2(→400MHz),
  Q=8, R=2；PLLRGE=VCIRANGE_3(输入8-16MHz), PLLVCOSEL=VCOWIDE(VCO 192-836MHz)。
- **验证结果**：SWD 读 g_sysclk_hz=0x17d78400(400M), g_hclk_hz=0x0bebc200(200M)；
  RCC_PLLCKSELR=0x02020200 → PLLSRC=HSE；Windows 枚举 COM4(CAFE:4001)；
  `clk` 命令打印 "PLL src HSE 25 MHz crystal (passive)"；CDC 回显 + 命令全部正常。
- 诊断手段：GDB 接 OpenOCD(`gdb_where.gdb`) 的 `bt` 直接定位到 error_trap ←
  system_clock_config(HAL_RCC_OscConfig 失败)，比手工 mww RCC 寄存器可靠
  （halt 态下 mww 外设寄存器有时不可靠）。
- **Windows 枚举**：COM4，VID:PID=CAFE:4001，序列号由 UID 生成，绑定 usbser.sys。
- **串口收发实测（test_cdc.py，pyserial 开 COM4）**：
  - 每次开启端口断言 DTR → 固件打印 banner（SYSCLK 400MHz / HCLK 200MHz / USB OTG_FS PA11/PA12）。
  - 逐字符回显正常；命令 help/clk/stats/led on|off/flood/hb 全部正确响应。
  - 心跳行（1Hz）正常输出，证明 device→host 持续可用。
- **SWD 交叉验证字节计数（OpenOCD mdw 直读 RAM）**：
  - `s_tx_bytes`@0x200002a8 = 0x63b(1595) → device→host 方向成立。
  - `s_rx_bytes`@0x200002ac = 0x6d(109)，与固件 stats 自报（53+56 长行=109）精确吻合 → host→device 方向成立。
- **单步仿真实测（GDB + OpenOCD，非 VSCode GUI 端到端）**：
  - 起 OpenOCD GDB server(3333)，arm-none-eabi-gdb 连接，halt → breakpoint cdc_task(main.c:190) → continue 命中 → stepi ×3（PC 0x80006f8→…fe，源码行跟随 cdc_task→tud_cdc_available）→ reset run → detach。
  - 证明 cortex-debug 的 F5 单步路径可用（launch.json 已配 Debug/Attach 两配置 + STM32H743.svd）。

# 2026-08-05（续）Phase 2 — 在 CDC 基础上增加 U 盘(MSC) + SD(FatFs)，两功能并发

## 需求
在已工作的 TinyUSB CDC 之上，增加 USB Mass Storage（U 盘）：
- SD 卡接 SDMMC1，引脚 PD2(CMD)/PC8(D0)/PC9(D1)/PC10(D2)/PC11(D3)，4-bit。
- 使用 FatFs；CDC 与 MSC 互不干扰、可同时运行。
- 鹿小班 STM32H743ZIT6，HSE 25MHz。

## 实现要点（已落地）
- **复合设备**：tusb_config.h 开 `CFG_TUD_MSC=1 / MAXLUN=1 / EP_BUFSIZE=512`。
  usb_descriptors.c 改为 CDC+IAD+MSC 复合描述符，新增 ITF_NUM_MSC、EPNUM_MSC_OUT 0x03 / IN 0x83，
  CONFIG_TOTAL_LEN 含 TUD_MSC_DESC_LEN，PID 改 CAFE:4003。Windows 自动绑 usbser(CDC)+usbstor(MSC)，无需 INF。
- **SDMMC1 驱动** `src/sdcard.c`：`HAL_SD_MspInit` 配 PC8-PC11/PD2 为 GPIO_AF12_SDMMC1 + 上拉；
  `system_clock_config` 中 `SdmmcClockSelection=RCC_SDMMCCLKSOURCE_PLL`(PLL1Q=100MHz)；
  `sdcard_init` ClockDiv=2(→25MHz)、4-bit；导出 present/block_count/block_size/read/write_blocks。
- **FatFs 胶水** `src/fatfs_diskio.c`：`disk_read/write/ioctl` 直接转 `sdcard_*`。
  配置 FF_USE_MKFS=1 / FF_CODE_PAGE=437 / FF_FS_NORTC=1；只用 ff.c + ffsystem.c（不用 ffunicode.c）。
- **MSC 回调** `src/msc_disk.c`：inquiry "STM32H7"/"SD_Card"；read10/write10 把 LBA+offset 翻译为
  `sdcard_read/write_blocks`（EP_BUFSIZE==扇区512，offset 恒 0）；scsi_cb 对 0x35 SYNCHRONIZE CACHE 返回 0；
  `tud_msc_start_stop_cb` 在 load_eject 时 start=1→`fatfs_release_for_host()`、start=0→`fatfs_reacquire()`。
- **并发仲裁 + CDC 命令** `src/sd_app.c`：
  - `g_host` 标志：host 占卡时释放设备侧 FatFs 挂载，避免两写者竞态破坏 FS。
  - 命令 `sd`/`ls`/`cat <f>`/`remount`/`help`/`clk`/`stats`。CDC 输出走无缓冲 `tud_cdc_write`（绕过 newlib 缓冲）。
  - **关键修正**：`ls`/`cat` 是只读操作，即使 host 占卡也允许（仅在并发写入时才可能破坏），
    因此放宽了原先对 g_host 的硬拒绝，使"host 写文件 → device 侧 cat 读回"回环可成立且 CDC 不断线。

## 构建 / 烧录
- `cmake --build build/debug`（preset debug，Ninja，arm-none-eabi-gcc 15.3，text ~61364B）。
- `openocd -f openocd/stm32h743_stlink.cfg -c "program build/debug/h743_tinyusb_cdc.elf verify reset exit"` → Verified OK。

## 验证结果（回环闭环 PASS）
- Windows 枚举：**COM7**(CDC, CAFE:4003) + **G: (STM32H7 SD_Card, 29.8GB FAT32)** 同时出现于同一复合设备。
- `sd`：capacity 62586880×512B=30560MB；host 写盘时 `host use : no`（见下方坑）。
- **回环证明**：host 写 `G:/rt.txt` = "RT-2026-08-05-ROUNDTRIP-OK-7F3A9C"（os.fsync 落地）→
  device `remount` + `cat rt.txt` 读到同一串；`ls` 列出 `RT.TXT`(33B)。CDC 心跳(up=70→75s)全程持续 → 两功能并发、互不干扰。

## 关键坑 / 经验
- **Windows 挂载 U 盘不一定发 START STOP UNIT(start=1)**：实测 `g_host` 始终为 false，
  设备侧 FatFs 挂载未被释放，host 与 device 两份 FS 视图共存。当前 device CLI 全为只读(ls/cat/remount)，
  实践安全；若将来加 device 侧写命令，必须 gating 在 host 占卡检查之后，或 host 接入期间不挂载 FatFs。
- 上一阶段 HSE 时钟结论沿用；SDMMC 时钟取 PLL1Q=100MHz（HAL_SD_Init 自动降到 ≤400kHz 识别卡片）。
- PowerShell `Set-Disk -IsOffline` 被策略阻断；但回环测试不需要 eject——host 写 + os.fsync 即落地，
  device 侧 `remount` 直读原始扇区绕过 Windows 缓存，因此无需安全弹出即可验证。
