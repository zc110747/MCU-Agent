# 2026-08-28

## 新增 MDK-ARM (Keil) 工程支持
- 在工程根目录创建 `MDK-ARM/`，放置 uVision 工程文件，支持 Keil/ARMCLANG 编译。
- 基于 `document/stm32h743/stm32h743.uvprojx` + `stm32h743.uvoptx`（原 FreeRTOS 模板）重写为本工程结构：
  - 单 Target `stm32h743`，参考 `CMakeLists.txt` 配置源文件/包含路径/编译宏。
  - 启动文件用 `sys_startup/arm/startup_stm32h743xx.s`（ARM 汇编版，非 gcc 版）。
  - 编译宏：STM32H743xx, USE_HAL_DRIVER, USE_PWR_LDO_SUPPLY, CFG_TUSB_MCU=OPT_MCU_STM32H7, CFG_TUSB_OS=OPT_OS_NONE, BOARD_TUD_RHPORT=0, USB_PORT_IS_FS=1。
  - 包含路径：src / Drivers/CMSIS/Core/Include / Drivers/CMSIS/Include / sys_startup / HAL Inc(+Legacy) / tinyusb/src / FatFs。
  - 5 个 Group：Application/Startup、Application/User/Core、Drivers/...HAL、Middlewares/TinyUSB、Middlewares/FatFs（共 31 个文件，与 CMakeLists 一致）。
  - 散列文件 `MDK-ARM/stm32h743.sct`（对照 `stm32h743zi_flash.ld`：FLASH 0x08000000/2MB、DTCM 0x20000000/128KB、AXI SRAM 0x24000000/512KB）。
- 编译产物全部隔离在 MDK-ARM 下：`OutputDirectory=Objects\`、`ListingPath=Listings\`、`.bin` 由 AfterMake `fromelf` 生成到 `Objects\`，不污染其它目录。
- 注意：`src/syscalls.c` 为 newlib 风格 retarget(_sbrk/_write)，Keil 标准 C 库(useUlib=0)下可能需改用 microlib 或调整 retarget；真机编译时再确认。
